# FeiSharp 零基础入门指南

> 这是一份写给“从来没有写过程序”的人的教程。
>
> 你不需要任何编程基础。即使 `print(1 + 1);` 对你来说像一串暗号，也可以从这里开始。本文第一次使用一个新词时，会先用普通话解释它。遇到暂时记不住的名字很正常：先照着做，看见结果，再回来读解释。

## 1. 我们到底要做什么

电脑不会自己猜人的意思。它只会按照十分明确的步骤做事。例如：

1. 算出一加一；
2. 把答案显示在屏幕上；
3. 询问一个人的名字；
4. 根据回答显示一句问候。

这样一组写给电脑的步骤，叫作**程序**。写这些步骤，叫作**编程**。

人平时说的话很灵活，“帮我算一下”对人很自然，电脑却不知道要算什么。于是，人们规定了一套严格一些的写法，让电脑和人都能辨认。这套写法叫作**编程语言**。FeiSharp 就是一种编程语言。用编程语言写下来的文字叫作**代码**。

请不要急着背。最有效的学习方法是：先猜运行结果，再运行，然后只改一个小地方，再运行一次。

## 2. 开始前：认识文件、编辑器和终端

### 2.1 文件是什么

电脑里的文章、照片和代码通常都保存在**文件**中。文件有名字，例如：

```text
hello.fsc
```

最后的 `.fsc` 是文件名的一部分。它告诉人和工具：“这里面写的是 FeiSharp 代码。”这种放在文件名末尾的部分叫作**扩展名**。

文件必须真的叫作 `hello.fsc`，不能是 `hello.fsc.txt`。如果 Windows 没有显示扩展名，可以在文件资源管理器的“查看”中勾选“文件扩展名”。

### 2.2 用什么写代码

能编辑普通文字的工具都可以写代码，例如记事本或 Visual Studio Code。这样的工具统称为**文本编辑器**。不要用 Word 写代码；Word 会保存字体、字号等额外内容，而代码文件只需要普通文字。

### 2.3 终端和命令是什么

平常我们通过点击按钮让电脑做事。也可以在一个窗口里输入文字，让电脑做事。这个窗口通常叫作**终端**。PowerShell 是 Windows 自带的一种终端。

在终端里输入的一整行操作要求叫作**命令**。输入后按回车键，电脑才会执行它。

制作一个程序时，相关代码和设置经常放在同一个文件夹中，这一整套内容叫作**项目**。本指南假定电脑已经安装 .NET 8，并且终端目前位于 FeiSharp 项目文件夹。可以输入下面的命令检查：

```powershell
dotnet --version
```

如果出现以 `8.` 开头的版本号，说明已经准备好。如果提示找不到 `dotnet`，需要先安装 .NET 8 SDK。这里的“SDK”可以简单理解成运行和制作程序所需的一套工具。

## 3. 第一次让电脑听你的话

在 FeiSharp 项目文件夹中新建文件 `hello.fsc`，输入：

```feisharp
printNl("你好！");
```

保存文件。保存就是把编辑器中的最新文字写进电脑里的文件；如果没有保存，电脑可能仍会运行旧内容。

在终端输入：

```powershell
dotnet run --project FeiSharp.csproj -- hello.fsc
```

按回车后，屏幕上会出现：

```text
你好！
```

第一次运行可能需要稍等。本终端版本在程序结束时可能显示“Press any key to exit”，意思是“按任意键退出”。按一下键即可。

命令的大意是：

- `dotnet run`：请 .NET 运行程序；
- `--project FeiSharp.csproj`：要运行的是 FeiSharp 项目；
- `hello.fsc`：请 FeiSharp 阅读并执行这个文件。

如果电脑上已经安装了 `feisharp` 命令，也可以运行 `feisharp hello.fsc`。

### 3.1 把第一行代码拆开看

```feisharp
printNl("你好！");
```

这行可以读成：“请 `printNl` 显示括号里的内容，然后换到下一行。”

- `printNl` 是 FeiSharp 已经准备好的一项功能；
- `(` 和 `)` 是一对圆括号，要显示的内容放在中间；
- 双引号告诉电脑：里面是要原样看待的文字；
- 最后的 `;` 是英文分号，表示这一条要求写完了。

代码里的标点通常必须用英文输入法输入。`()`、`""` 和 `;` 不能写成中文输入法产生的 `（）`、`“”` 和 `；`。

自己改一改：

```feisharp
printNl("我正在学习 FeiSharp");
printNl("这是第二行");
```

电脑会从上到下执行。一次写给电脑的完整要求，常叫作一条**语句**。上面有两条语句。

## 4. 数字和最简单的计算

```feisharp
printNl(8);
```

这里的 `8` 没有双引号，因为它是可以计算的数字，不是普通文字。

```feisharp
printNl(1 + 1);
```

电脑会先算出 `1 + 1` 的答案 `2`，再把 `2` 交给 `printNl` 显示。所以 `printNl` 显示的不一定是原样写下的内容，也可以是计算结果。

| 写法 | 日常说法 | 例子 | 结果 |
| --- | --- | --- | --- |
| `+` | 加 | `7 + 2` | `9` |
| `-` | 减 | `7 - 2` | `5` |
| `*` | 乘 | `7 * 2` | `14` |
| `/` | 除 | `8 / 2` | `4` |
| `$` | 乘方 | `2 $ 3` | `8` |

乘号写作 `*`，不是 `×`；除号写作 `/`，不是 `÷`。

普通数学中乘法先于加法：

```feisharp
printNl(2 + 3 * 4);     // 14
printNl((2 + 3) * 4);   // 20
```

`//` 以及它右边的内容是给人看的说明，电脑不会执行，后文会详细解释。

### 4.1 数字和文字不是一回事

```feisharp
printNl(1 + 1);
printNl("1 + 1");
```

第一行显示 `2`。第二行显示 `1 + 1`，因为双引号表示“把里面原样当作文字”。电脑必须区别可计算的数字和用于阅读的文字。这样的不同种类，之后会叫作不同的**数据类型**。现在只要记住：带双引号的是文字，不带引号的 `123` 才是数字。

## 5. 用名字保存结果

```feisharp
var price = 12;
var count = 3;
printNl(price * count);
```

结果是 `36`。`var price = 12;` 可以从右向左理解：

1. 右边是数字 `12`；
2. `=` 在这里表示“把右边内容交给左边的名字”；
3. `price` 是我们起的名字；
4. `var` 告诉电脑：“我要第一次创建这个名字。”

这种用来保存一个内容的名字叫作**变量**。可以把变量想成贴了标签的盒子：`price` 是标签，`12` 是盒子里当前装的内容。

### 5.1 变量可以改变

```feisharp
var score = 60;
printNl(score);

score = 85;
printNl(score);
```

第一次显示 `60`，第二次显示 `85`。第二次没有写 `var`，因为 `score` 已经创建过了。

### 5.2 怎样起名字

初学时遵守下面几条就够了：

- 使用英文字母，可以加入数字和下划线；
- 不要以数字开头；
- 多个单词连写时，从第二个单词起把首字母大写；
- 名字要能说明内容。

```feisharp
var userName = "小飞";
var age = 18;
var totalPrice = 36;
```

FeiSharp 查找名字时不区分英文字母大小写，但自己书写时最好一直保持相同写法。

### 5.3 不允许修改的名字

```feisharp
const daysInWeek = 7;
```

`const` 创建的是不能再次修改的名字，通常叫作**常量**。如果后面写 `daysInWeek = 8;`，程序会报错。“报错”就是电脑告诉你某处无法按规则继续执行。

## 6. 把文字连接起来，并写说明

```feisharp
var name = "小飞";
var age = 18;
printNl("你好，" + name + "！");
printNl("我今年 " + age + " 岁");
```

`+` 在这里把几段内容接成一段文字。把文字连接起来常叫作**拼接**。FeiSharp 会在显示时把数字 `18` 写成可阅读的文字。

代码中还可以加入电脑不执行的说明：

```feisharp
// 从这里到本行末尾都是说明
var price = 12;

/*
这也是说明。
它可以占据多行。
*/
printNl(price);
```

这种说明叫作**注释**。好注释通常解释“为什么这样做”，而不只是重复代码。

## 7. 是与不是：让电脑回答问题

```feisharp
printNl(80 >= 60);  // true
printNl(40 >= 60);  // false
```

`true` 是“真”，可以理解为“是，条件成立”；`false` 是“假”，可以理解为“不，条件不成立”。

| 写法 | 意思 | 例子产生的回答 |
| --- | --- | --- |
| `a > b` | a 大于 b | `5 > 3` 是 `true` |
| `a < b` | a 小于 b | `5 < 3` 是 `false` |
| `a >= b` | a 大于或等于 b | `5 >= 5` 是 `true` |
| `a <= b` | a 小于或等于 b | `4 <= 5` 是 `true` |
| `a = b` | a 与 b 相等 | `5 = 5` 是 `true` |
| `a != b` | a 与 b 不相等 | `5 != 3` 是 `true` |

FeiSharp 的 `=` 有两种用途：单独写 `score = 90;` 是修改变量；写在 `printNl(score = 90);` 这样的计算中，是询问两边是否相等。电脑会根据它所在的位置判断。

`true` 和 `false` 也能保存在变量中：

```feisharp
var hasTicket = true;
var isAdult = false;
```

这种只有“真”和“假”两种可能的内容叫作**布尔值**。记不住这个名词不影响使用。

## 8. 用 `if` 作选择

```feisharp
var score = 78;

if (score >= 60) {
    printNl("及格了");
} else {
    printNl("还需要继续努力");
}
```

逐步读它：

1. `if` 是“如果”；
2. 圆括号里是要回答的问题；
3. 答案为 `true`，执行第一对花括号 `{}` 中的语句；
4. `else` 是“否则”；
5. 答案为 `false`，执行 `else` 后花括号中的语句。

每行开头留出的空格叫作**缩进**。它让人容易看出哪些语句在花括号里面。

多种情况可以继续判断：

```feisharp
var score = 86;

if (score >= 90) {
    printNl("优秀");
} else {
    if (score >= 60) {
        printNl("及格");
    } else {
        printNl("不及格");
    }
}
```

### 8.1 同时问几个问题

```feisharp
var age = 20;
var hasTicket = true;

if (age >= 18 && hasTicket) {
    printNl("可以入场");
}
```

`&&` 表示左右两个问题都必须是 `true`。`||` 表示左右至少一个是 `true`。`!` 表示把答案反过来。

```feisharp
printNl(true && true);   // true
printNl(true || false);  // true
printNl(!true);          // false
```

这些符号常叫作**逻辑运算符**，其实就是日常说的“并且”“或者”“不是”。

## 9. 让电脑重复做事

让一组语句重复执行，叫作**循环**。

### 9.1 `while`：只要条件成立，就继续

```feisharp
var number = 1;

while (number <= 5) {
    printNl(number);
    number = number + 1;
}
```

电脑会检查 `number <= 5`，成立就显示数字并加一，然后重新检查。`number` 变成 6 时，问题不再成立，循环结束。

如果忘了让 `number` 增加，条件会一直成立，程序也会一直运行。这叫作**无限循环**。遇到它时，可以在终端按 `Ctrl+C` 尝试停止。

### 9.2 `for`：把计数需要的三件事写在一行

```feisharp
for (var i = 1; i <= 5; i = i + 1) {
    printNl(i);
}
```

圆括号里用两个分号分成三段：

1. `var i = 1`：开始前让 `i` 为 1；
2. `i <= 5`：每次开始前检查是否继续；
3. `i = i + 1`：每次做完后加一。

`i` 只是变量名，常用来表示“现在是第几次”。`i++` 是 `i = i + 1` 的简写，初学时使用较长写法完全没有问题。

## 10. 把工作做成可反复使用的小工具

```feisharp
function greet(name) {
    printNl("你好，" + name + "！");
}

greet("小飞");
greet("小明");
```

从 `function` 开始的部分是在制作工具：`greet` 是工具名，`name` 是每次使用时可以送进去的内容，花括号里是具体工作。最后两行是在使用它。

这样有名字、可以反复使用的一组工作叫作**函数**。送给函数的内容叫作**参数**。可以把函数想成小机器：送进去原料，机器完成一项工作。

### 10.1 让函数交回答案

```feisharp
function add(a, b) {
    return a + b;
}

var answer = add(20, 22);
printNl(answer);
```

`a` 暂时代表 20，`b` 暂时代表 22。`return` 表示“把后面的结果交回使用函数的地方”，所以 `answer` 得到 42。函数也可以只做事而不交回答案，例如前面的 `greet`。

### 10.2 `main`：程序的主要部分

稍长的程序建议写成：

```feisharp
function main() {
    printNl("程序从这里开始");
}
```

`main` 是约定好的名字，意思是“主要部分”。运行器看到准确写法 `function main(` 时会使用它。不要再在文件末尾手动写 `main();`，否则可能执行两次。

## 11. 一次保存多个内容

```feisharp
var scores = [88, 95, 76, 100, 82];
```

方括号围住所有分数，逗号把它们分开。这样按顺序放在一起的一批内容叫作**数组**，其中每一个内容叫作一个**元素**。

```feisharp
printNl(scores[0]);  // 88
printNl(scores[1]);  // 95
```

数组从 0 开始编号。元素的位置编号叫作**下标**。五个元素的下标是 0、1、2、3、4。访问 `scores[5]` 会因位置不存在而报错，这叫作“下标越界”。

```feisharp
scores[1] = 98;
```

这会修改第二个元素。

### 11.1 逐个处理所有元素

```feisharp
var fruits = ["苹果", "香蕉", "橙子"];

foreach (var fruit in fruits) {
    printNl("我喜欢 " + fruit);
}
```

`foreach` 可以读成“对于其中的每一个”。程序每次取出一个元素，暂时叫它 `fruit`，然后执行一次花括号里的语句。

### 11.2 一共有多少个

```feisharp
printNl(len(scores));
printNl(scores.Length);
```

两行都会得到元素数量。`len` 是 FeiSharp 准备好的函数。第二行的点 `.` 可以读成“这个东西的”，所以 `scores.Length` 是“scores 的长度”。一个东西自己带有的信息和功能，合称它的**成员**；其中像 `Length` 这样用来描述它的信息，又常叫作**属性**。

## 12. 完整小项目：平均分

保存为 `score_app.fsc`：

```feisharp
function average(scores) {
    var total = 0;

    foreach (var score in scores) {
        total = total + score;
    }

    return total / len(scores);
}

function showLevel(score) {
    if (score >= 90) {
        printNl("优秀");
    } else {
        if (score >= 60) {
            printNl("及格");
        } else {
            printNl("需要继续努力");
        }
    }
}

function main() {
    var scores = [92, 78, 55];
    var result = average(scores);

    printNl("平均分：" + result);
    printNl("第一位同学的情况：");
    showLevel(scores[0]);
}
```

`average` 从 0 开始，把每个分数加到 `total`，最后用总分除以人数。`showLevel` 根据一个分数作选择。`main` 准备数据并使用前两个函数。这里没有新本领，只是把变量、循环、函数、数组和判断组合起来。

请依次尝试：

1. 把 55 改成 65；
2. 在数组末尾增加一个分数；
3. 显示第二位同学的等级；
4. 把优秀线改成 85；
5. 写一个找最高分的函数。

答案之一：

```feisharp
function highest(scores) {
    var best = scores[0];

    foreach (var score in scores) {
        if (score > best) {
            best = score;
        }
    }

    return best;
}
```

它先把第一个分数当作目前最高分。以后每看到更大的分数，就更新 `best`。

## 13. 接收键盘输入

```feisharp
function main() {
    printNl("请输入你的名字，然后按回车：");
    readLine("name");
    printNl("你好，" + name + "！");
}
```

`readLine` 是“读取一行输入”。`readLine("name")` 会等待使用者输入，把结果保存在名为 `name` 的变量中，然后继续。

当前 FeiSharp 不写 `var name = readLine();`，必须使用上面的特别写法。

键盘输入会先被当作文字。即使输入 `18`，最初得到的也是文字，需要转换后才能计算：

```feisharp
function main() {
    printNl("请输入你的年龄：");
    readLine("ageText");

    var age = number.parse(ageText);
    printNl("明年你 " + (age + 1) + " 岁");
}
```

`number.parse(ageText)` 可以读成“尝试把 `ageText` 中的文字理解成数字”。如果输入“十八岁”而不是 `18`，电脑无法完成转换，就会报错。

## 14. 现在再认识“数据类型”和“动态类型”

我们已经实际用过这些内容：

```feisharp
var count = 12;                 // 数字
var price = 19.9;               // 有小数的数字
var title = "入门课";           // 文字
var finished = false;           // 真或假
var scores = [88, 95, 76];      // 数组
```

电脑处理它们的方式不同。为了谈论这种区别，人们把内容所属的种类叫作**数据类型**，简称“类型”。

还可能看到：

```feisharp
var grade = 'A';
var nothing = null;
```

单引号里的 `'A'` 表示单独一个文字符号。`null` 表示“这里目前没有内容”，它不是数字 0，也不是空文字。

```feisharp
printNl(typeOf(123));
printNl(typeOf("你好"));
printNl(typeOf(true));
printNl(isNull(null));
```

`typeOf` 告诉我们内容的类型；`isNull` 询问内容是否为 `null`。

创建变量时只写 `var thing = 10;`，不必另外声明“thing 必须是数字”。FeiSharp 会根据当前内容处理它。这样的语言通常称为**动态类型语言**。它不代表所有内容都一样，也不代表文字可以随便做除法。初学阶段无需记住这个术语，只要知道数字和文字的用途不同。

## 15. 更多保存一批内容的方法

本节比数组难，可以先跳过。

### 15.1 列表：方便追加内容

```feisharp
var names = new List<string> { "小飞", "小明" };
names.Add("小红");

printNl(names[0]);
printNl(names.Count);
```

- `new` 表示新建；
- `List` 表示列表；
- `<string>` 表示其中准备保存文字，`string` 是“文字”类型的常用英文名；
- `names.Add("小红")` 使用 `names` 的 `Add` 功能追加内容；
- `names.Count` 是内容数量。

“用点号找到的功能”通常叫作**方法**。它和函数很像，只是属于一个具体的东西。

### 15.2 字典：用一个内容查另一个内容

```feisharp
var scores = new Dictionary<string, int> {
    { "小飞", 92 },
    { "小明", 85 }
};

printNl(scores["小飞"]);
scores["小明"] = 90;
```

字典像通讯录。`Dictionary<string, int>` 表示“用文字查整数的字典”；`int` 是 integer 的缩写，表示没有小数部分的整数。`"小飞"` 是用来查找的**键**，92 是查到的**值**。

## 16. 错误并不可怕

少一个分号、漏一个引号或写错名字，电脑都可能无法继续。它显示的说明叫作**错误信息**。

遇到错误时依次检查：

1. 看错误指出的文件和位置；
2. 检查上一行和当前行的分号；
3. 检查 `()`、`[]`、`{}` 和引号是否成对；
4. 检查变量名拼写是否一致；
5. 确认使用变量前已经用 `var` 创建；
6. 加入 `printNl`，看看执行到了哪里；
7. 暂时删减无关部分，留下仍会出错的最短代码。

类似 `FS3004` 的编号叫作**错误码**，方便辨认同一种问题。

| 错误码 | 普通话解释 | 首先检查什么 |
| --- | --- | --- |
| `FS2004` | 某个符号缺失 | 括号、逗号、点和分号 |
| `FS3004` | 找不到这个名字 | 是否拼错，是否先创建或定义 |
| `FS3005` | 交给某项功能的内容不合要求 | 数量或数字范围 |
| `FS3006` | 内容种类不合适 | 是否把文字当数字计算 |
| `FS3007` | 没有这个位置 | 下标是否从 0 开始且小于数量 |
| `FS3008` | 没有内容却对它操作 | 是否得到了 `null` |
| `FS3009` | 修改了不许修改的内容 | 是否修改 `const` 常量 |

寻找和修正程序问题的过程叫作**调试**。调试不是失败，而是编程本身的一部分。

## 17. 可以晚一点再学的内容

### 17.1 文件操作

```feisharp
using FeiSharp.IO;

function main() {
    var fileName = "notes.txt";
    file.writeText(fileName, "今天开始学习 FeiSharp");
    printNl(file.readText(fileName));
}
```

`using FeiSharp.IO;` 表示启用负责文件操作的一组功能。这样一组有名字的功能区域叫作**命名空间**，可以把它想成工具箱。`writeText` 写入文字，`readText` 读取文字。

### 17.2 把代码分到多个文件

在 `helpers.fsc` 中写：

```feisharp
function doubleValue(value) {
    return value * 2;
}
```

在另一个同文件夹的文件中写：

```feisharp
import "helpers.fsc";

function main() {
    printNl(doubleValue(21));
}
```

`import` 可以理解为“先把另一个代码文件也带进来”。

### 17.3 类、对象和字段

如果程序要描述许多相似的东西，可以先写一张共同设计图。设计图叫作**类**，按图创建出的某一个具体东西叫作**对象**。

```feisharp
class counter {
    private var value = 0;

    constructor(start) {
        this.value = start;
    }

    public function add(amount) {
        this.value = this.value + amount;
        return this.value;
    }
}

function main() {
    var myCounter = counter(10);
    printNl(myCounter.add(5));
}
```

- `class counter` 定义名为 `counter` 的设计图；
- `value` 是每个计数器自己保存的数字，这种属于对象的变量叫作**字段**；
- `constructor` 是创建对象时执行的准备工作；
- `this` 表示“当前这个对象自己”；
- `private` 表示只允许类内部使用；
- `public` 表示允许外部使用；
- `counter(10)` 创建一个从 10 开始的计数器；
- `myCounter.add(5)` 让这个计数器增加 5。

如果仍然抽象，完全可以跳过。先熟练掌握函数和数组，再学习类会容易很多。

## 21. 接下来怎样学

如果能独立完成第 18 节的大部分练习，你就已经越过真正的“零基础”阶段。接下来可以：

1. 做一个几十行的小程序，例如成绩统计、简单记账或猜数字；
2. 每次只增加一项功能，运行成功后再继续；
3. 遇到错误时先缩小问题，不要同时乱改许多地方；
4. 用自己的话解释每一行“现在有什么、做了什么、得到什么”；
5. 再阅读同目录下的《FeiSharp 程序员指南》，学习更完整、更精确的规则。

最后请记住：看不懂一个新词，不代表你不适合编程，通常只代表解释者跳过了一步。退回最近一个完全看懂的例子，每次只增加一个符号或一个想法，你就能继续向前。
